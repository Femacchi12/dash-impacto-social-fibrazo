# FIBRAZO Forms · MVP 0.1

Primera versión del centro de formularios FIBRAZO.

## Diseño
Replica la lógica visual del Dashboard de Impacto Social: Inter, fondo negro, superficies carbón, verde `#00f29a`, controles compactos, paneles de 14 px y jerarquías equivalentes.

## Formularios
- Churn — Sincelejo / Montería, con preguntas condicionales.
- Exploración — infraestructura, operadores, GPS y hasta 3 fotos.

## GitHub Pages
La carpeta se puede previsualizar en `/forms/`. En `github.io` las respuestas quedan en `localStorage` para no aparentar una escritura real al backend.

## Vercel
Usar `forms` como Root Directory y configurar las variables de `.env.example`. Compartir el Sheet y las carpetas de fotos con la cuenta de servicio de Google.
